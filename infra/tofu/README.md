This optional OpenTofu module provisions Docker network and persistent volumes for a separate staging/production deployment. It does not replace local Compose or pretend to provision a cloud platform. Run `tofu init`, `tofu plan -var='docker_host=unix:///Users/YOU/.docker/run/docker.sock'`, then `tofu apply` when ready. Use the output resource names in your deployment override. Keep state outside Git. Production requires TLS, a secret manager, backups, non-superuser PostgreSQL roles, and separately managed n8n templates. No cloud credentials required.
